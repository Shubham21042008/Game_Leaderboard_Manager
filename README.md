# Game_Leaderboard_Manager# 
🎮 Game Leaderboard Manager

## 📌 About the Project

Game Leaderboard Manager is a simple C++ project that manages player names and scores. It helps users maintain a leaderboard, arrange players according to their scores, and track player performance.

## ✨ Features

* Add player names and scores.
* Display all players.
* Sort players by score.
* Compare player performance.
* Search and remove players using rank.
* Save leaderboard data.
* Load saved leaderboard data.
* Generate random scores for simulation.

## 🛠️ Technologies Used

* Programming Language: C++
* Concepts: Classes, Objects, Arrays, Functions, Sorting, and File Handling.

## ▶️ How to Run

1. Download or clone this repository.

2. Open the project in VS Code.

3. Open the terminal.

4. Compile the program:

   ```bash
   g++ GameLeaderboard.cpp -o GameLeaderboard
   ```

5. Run the program:

   ```bash
   .\GameLeaderboard
   ```

## 🎯 Project Objective

The main objective of this project is to understand C++ programming concepts and learn how to manage player scores using a leaderboard system.
